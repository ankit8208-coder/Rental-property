Rental Property Management Portal — API

OpenAPI JSON: /api-docs.json

POST /api/auth/register — register tenant/owner
POST /api/auth/login — login and receive JWT
GET /api/auth/me — current authenticated user
GET /api/properties — search/filter properties
POST /api/properties — owner/admin creates property
PUT /api/properties/:id — update property
DELETE /api/properties/:id — delete property
POST /api/properties/:id/images — upload images
POST /api/rental-requests — tenant submits request
GET /api/rental-requests/mine — tenant requests
GET /api/rental-requests/owner — owner/admin requests
PATCH /api/rental-requests/:id/status — approve/reject
GET /api/profile — profile
PUT /api/profile — update profile
GET /api/admin/stats — admin stats
GET /api/admin/users — list users
GET /api/admin/properties — list properties
PATCH /api/admin/properties/:id/status — approve/reject listing
